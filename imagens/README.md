# Fotografias dos marcadores

Adicione aqui as fotografias originais dos marcadores de página.

## Como nomear os arquivos

O catálogo já está preparado para reconhecer estes nomes:

- `marcador-01.jpg`
- `marcador-02.jpg`
- `marcador-03.jpg`
- ... até `marcador-12.jpg`

Também são aceitos os formatos `.jpeg`, `.png` e `.webp`. O número no nome deve corresponder à posição do modelo no arquivo `catalogo.js`.

Para incluir mais modelos, adicione uma nova entrada ao final de `catalogo.js` e envie a respectiva fotografia para esta pasta. As imagens aparecem automaticamente na galeria do site.

**Dica:** prefira fotos verticais, bem iluminadas e com o marcador ocupando boa parte do enquadramento.
